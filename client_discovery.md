# ISO 27001 Client Discovery Questionnaire

> **Purpose:** This questionnaire is used during the initial discovery session of an ISO 27001 audit engagement. Answers will be used to assess the current state of the client's information security management system (ISMS) and to populate applicable security policies.
>
> **Instructions:** Complete as much as possible before the opening meeting. Items left blank will be discussed during the session. Attach supporting documents (org charts, process diagrams, existing policies) where available.
